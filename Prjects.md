# 📊 Sales Performance Dashboard | Microsoft Excel

## 🚀 Excited to Share My Latest Excel Dashboard Project!

I'm excited to share my **Sales Performance Dashboard**, created using Microsoft Excel!

This dashboard provides a clear and interactive-style visualization of sales performance across multiple cities and sales executives. The goal of this project is to transform sales data into meaningful insights through effective data visualization.

### ✨ Dashboard Highlights

📍 **City-Wise Analysis**
- Chennai
- Delhi
- Mumbai
- Nagpur
- Patna
- Pune
- Ranchi
- Surat

📊 **Four Dashboard Sections**

1. **Total Sales Analysis** – Visualizes sales performance using a horizontal bar chart.
2. **Sales Executive Summary** – Presents sales figures for individual executives.
3. **Target Hit % Analysis** – Displays target achievement percentages using a pie chart.
4. **Away From Target % Analysis** – Compares percentage values using a line chart.
